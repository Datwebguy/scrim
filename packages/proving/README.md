# Proposed proof boundary

No verifier or circuit is implemented in Milestone 1. Shielded-pool interfaces and receipt, solvency, and payroll-total verification methods remain proposals. Reader key, nonce, expiry, statement commitment, verification-key version, and single-use semantics must be rechecked against the actual circuit/public-input design before any implementation is accepted. No API can issue an unsigned statement and call it a cryptographic proof.
